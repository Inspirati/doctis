
================== Using Doctis/Mantis ==================
1. As administrator, select sidebar 'Manage' then tab 'Projects'
2. Add a new 'test' project
3. Select sidebar 'Create Document' then submit a new document
4. Select sidebar 'Report Issue' and submit an issue
5. Explore and experiment

================ Development Environment ================
1. If not already open, start codium and select <File> <Open Folder> /var/www/html/doctis
2. Start a debug session with menu <Run><Start Debugging> or press <F5>
3. Open source file view_all_bug_page.php and set a break-point on or around line 50
    (breakpoints can be set by clicking in the margin to the left of a line number, or with <F9>)
4. If required, start Firefox at <FQDM>/doctis (insert Fully Qualified Domain Name, or server IP address)
5. In doctis select 'View Issues' from the sidebar
    (observe that execution has halted in codium at the set breakpoint)
6. Press <F10> to step through the code, or <F11> to step into function calls
7. View status (diff) of source file changes from the original mantisbt source:
    on the git staging source code in the install directory:
      $ meld doctis mantisbt &
    or on the live server source code via soft-links:
      $ meld doctis-www mantisbt-www &
    or directly in the webserver root directory:
      $ meld /var/www/html/doctis /var/www/html/mantisbt &
8. Set a tail on the webserver (apache) error log:
    $ trace
9. Optionally, set a tail that filters for thrown exceptions only:
    $ tracex

NOTES:
1. if you elected to install the VirtualBox Client Tools, a reboot is required to take effect
2. phpMyAdmin username is 'admin', password as per install script ie. default is: 'password'
3. a default doctis 'admin' account has been created, the default password is always: 'password'
4. there are default accounts which correspond to each access level, being: viewer, user, reporter, updater, developer, and manager - the default password for these accounts is '' (blank)
5. you can create new or modify existing user accounts when logged in as 'admin'
